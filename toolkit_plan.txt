Personal Mini-Toolkit Plan

1. Chosen Tools:
- Tool 1: To-Do List Manager - Allows users to view, add, and remove tasks from an active task list.
- Tool 2: Simple Calculator - Performs basic arithmetic (addition, subtraction, multiplication, division) based on user numbers.
- Tool 3: Number Guessing Game - Generates a secret number and loops until the user guesses it correctly using conditional hints.

3. Concepts Used:
- To-Do List: Lists, loops, conditionals, f-strings
- Simple Calculator: Conditionals, input/output, f-strings
- Number Guessing Game: Loops, conditionals, random module, f-strings
